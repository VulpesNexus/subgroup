Subgroup {VERSION} — Adobe Illustrator plugin
Windows x64. Built against the Illustrator 2026 SDK, tested on 30.7.

DO NOT DOUBLE-CLICK Subgroup.aip

  It is a plugin, not a document. Double-clicking it, or dragging it onto
  Illustrator, makes Illustrator try to OPEN it as artwork, and it answers:

      "Subgroup.aip" cannot be opened because the file format is unknown.

  Nothing is wrong with the file when that happens. A plugin is installed by
  putting it in a folder Illustrator reads at startup, which is the steps
  below.


INSTALL
  1. Put Subgroup.aip in
       %LOCALAPPDATA%\Adobe Illustrator Plug-ins\30
     The 30 is Illustrator 2026's version number. Next year's Illustrator
     gets its own folder beside it: a plugin built against one year's SDK is
     not guaranteed to load in another, and this one does not load in
     Illustrator 2025.
  2. Illustrator > Preferences > Plug-ins & Scratch Disks, and point
     "Additional Plug-ins Folder" at that folder.
  3. Restart Illustrator.

  SHARE THAT FOLDER with your other Illustrator plugins. Illustrator has one
  Additional Plug-ins Folder, not a list, so giving each plugin a folder of
  its own means pointing the preference at the newest one silently stops the
  rest from loading. Everything in the one folder loads.

  No admin rights are needed. Deleting the .aip uninstalls it. Replacing the
  file needs Illustrator fully closed — it holds the plugin open while running.

WHAT YOU GET
  Object > Subgroup

    Nest Down                  add a level of grouping INSIDE the selection,
                               including when the selection is a whole group
    Nest Up                    add a level AROUND it instead
    Nest Whole Groups          on: Nest Down acts on a whole-group selection
                               off: it declines, exactly as Object > Group does
    Keep New Groups Open       leave a new group expanded in the Layers panel
    Align Group To Selected ▸  select ONE object inside a group and its
                               siblings move to meet it

SHORTCUTS
  All five commands are assignable under Edit > Keyboard Shortcuts… > Menu
  Commands > Object > Subgroup, like any other menu command.

  Nest Down is the one worth a key. Giving it Ctrl+G makes grouping simply start
  working where Illustrator declines; Illustrator will warn that Ctrl+G belongs
  to Object > Group, and accepting is safe — clearing the assignment restores
  stock behavior completely.

  The plugin never touches your keyboard set itself. Illustrator does not honor
  a plugin's claim over a built-in's shortcut, and trying anyway rewrites your
  saved set at every launch, so the choice stays yours.
